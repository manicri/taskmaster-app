# TaskMaster Web 🌐

Aplicación web interactiva, moderna y altamente responsive para la gestión integral de tareas pendientes, fechas límites y prioridades.

## ✨ Características Principales
- **Dashboard de Estadísticas en Vivo**: Total de tareas, pendientes, completadas, porcentaje de efectividad y barra de progreso animada.
- **Fechas y Horas Límite**: Selector interactivo (`datetime-local`) con indicadores dinámicos de estado (Hoy, Mañana, En X días, Vencida ⚠️).
- **Filtros Avanzados**:
  - Filtro por Categoría (Trabajo, Personal, Estudio, Salud, Finanzas, Otros).
  - Filtro por Estado (Todas, Pendientes, Completadas).
- **Buscador en Tiempo Real**: Filtrado reactivo por título o contenido de la descripción.
- **Opciones de Ordenamiento**: Por fecha límite más próxima, prioridad, más recientes o alfabético.
- **Tema Claro y Oscuro**: Detección automática y botón de cambio de tema persistente.
- **Exportación e Importación**: Respaldo y carga de tareas mediante archivos JSON.
- **Almacenamiento Local (LocalStorage)**: Todas las tareas quedan guardadas en tu navegador sin requerir servidores externos.

## 🚀 Cómo abrir la aplicación web
1. Puedes abrir directamente el archivo `index.html` en cualquier navegador (Google Chrome, Edge, Firefox, Safari).
2. O bien servirlo con cualquier servidor local (como Live Server de VS Code, o con `npx serve .`).
