# TaskMaster Android 📱

Aplicación nativa de gestión de tareas y pendientes desarrollada con **Kotlin**, **Jetpack Compose** y **Material Design 3**.

## ✨ Características Principales
- **Gestión Completa de Tareas**: Agregar, editar, eliminar y marcar como completadas.
- **Fechas y Horas Límite**: Selector interactivo de calendario y reloj con detección de tareas vencidas.
- **Niveles de Prioridad**: Alta (Rojo), Media (Ámbar) y Baja (Verde).
- **Categorías**: Trabajo, Personal, Estudio, Salud y Otros.
- **Buscador en Tiempo Real**: Filtrado instantáneo por texto en título o descripción.
- **Métricas y Progreso**: Barra de progreso animada con porcentaje de tareas completadas.
- **Persistencia Local**: Base de datos SQLite nativa para almacenar datos de forma segura sin conexión a internet.
- **Arquitectura Limpia**: ViewModel + StateFlow + Repositorio.

## 🚀 Cómo abrir y compilar el proyecto
1. Abre **Android Studio**.
2. Selecciona **File -> Open...** y elige la carpeta `TodoApp-Android`.
3. Espera a que Gradle sincronice las dependencias.
4. Conecta tu teléfono Android (o inicia un emulador) y presiona **Run (Shift + F10)**.
